# 真机验收步骤（尚未执行）

本清单由设备所有者执行，或在单独授权安装 APK、开启相机后由测试人员执行。本预发布尚未进行手机或相机实测。

## 设备与安装

记录品牌/型号、Android版本、ABI、屏幕尺寸、是否16KB内存页、应用版本和APK SHA-256。最低Android 8.0 / API26，设备需具备Camera2 YUV相机。先核对校验和，再使用设备正常安装流程；本包用公开AOSP测试签名，只供验收，生产签名须由所有者提供。

安装后应仅显示“相机”权限。拒绝相机后不能显示虚构计数，界面应提供重试/系统应用设置说明。未点击开启相机时，首页不访问相机。

## 功能与中断

1. 自由模式：全身入镜、站稳约1秒，开始按钮可用。倒数3秒不计入运动时长；只在倒数结束后统计双脚跳跃。按暂停，计数和计时冻结、系统相机指示消失；按继续，站稳重新校准后恢复。结束后本地历史只出现一条。
2. 定时30秒：观察倒数和计划结束；运动时长应为30秒，最后一帧不能在已结束后加数。记录状态“计划完成”。
3. 分组2组×30秒、休息10秒：休息时进行10次跳跃，总数不得增加；第2组重新校准，结束后不再安排多余休息，记录含每组次数及实际运动时长。
4. 运动/倒数/休息三个阶段分别按Home、锁屏、打开其他应用、接听电话、打开权限设置：训练自动暂停，TTS停止，相机释放。等待60秒再返回，不应补算后台时长或自动继续。休息阶段恢复剩余休息时间应正确。
   另测刚点击“开启相机”且预览尚未出现时立即按Home/锁屏：即使系统稍后才返回打开回调，也应关闭相机，不能在后台残留预览或相机指示。恢复需手动操作。
5. 训练中离开画面超过3秒，自动暂停。相机被其他应用占用或画面中断超过2.5秒，提示暂停并可重试。授权被撤销时不给出“仍在计数”的状态。
6. 训练中切换前后摄像头，应先暂停；恢复后重新校准，不得因镜像或旋转多加一次。检查横屏握持、平板、刘海屏、放大字体和TalkBack点击范围。
7. 在有离线中文音色的设备上开启飞行模式，测试每1/10/20个报数、休息和完成提示。缺少音色时明确显示“语音不可用”，可静音继续，不自动下载或要求联网。暂停和后台不得继续说话。
8. 刚完成一次训练后重开应用；再在训练中强制结束进程后重开：已结束记录存在，未结束训练恢复为暂停，不自动开相机，次数保留到最近一次成功写入，时长检查点最多落后约1秒。多次恢复/保存不应重复记录。
9. 如具备受控测试设备，模拟磁盘写入失败：不能声称保存成功；必须显示重试且保留本次结果。恢复磁盘后重试应仅生成一条。模拟文件校验损坏时原文件保留，禁止覆盖，历史读取异常应清楚显示。
10. 清除历史需确认；取消不删除，确认只删除本机历史。卸载/清除数据会移除本地记录。无网络权限，不应产生应用网络连接，也无录像或照片文件。

## 真人计数准确率：独立记录，不能用合成测试替代

测试至少使用3名获得同意的成年人、2部不同档位手机，室内明亮/侧光/较暗场景，正面2米/3米，浅/深色服装。每个场景以60/120/180/220次每分钟目标节奏完成3段，每段100个双脚跳。另测停顿、绊绳、空跳、双摇、交替脚、蹲起、摆臂、旁人经过和手机震动，明确算法支持边界。

MoveNet SinglePose只输出一人的关键点，无法可靠判断画面中是否有第二人，也不能可靠锁定多人场景中的同一人。旁人进入时应手动暂停；本版不宣称具备多人检测或跟踪能力。

由独立观察者手动计数作为ground truth；如需录像，必须先另获人物与设备所有者同意，并在外部工具操作，不通过本应用默认录制。记录：

|---|---:|---:|---:|---:|---:|---|---|
| 待测 | | | | | | | |

误差率 = `abs(应用次数−人工次数)/人工次数`；同时列漏计、多计，不能仅报告总体净差抵消后的好看数字。建议门槛是明亮正面双脚跳多数场景误差≤5%，但这只是验收目标，当前未证明达标。不能宣称支持绳圈识别：原地无绳双脚跳也可能被统计；双摇只记一次起落，交替脚不属于本版范围。
